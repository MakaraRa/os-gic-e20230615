1. Relative path used to move the first report:

   cp -- "reports/$file1" "reports/$file2" "TechCorp/$owner/"

   cat "$OSLAB_WORKSPACE/lab2/reports/$file1"

5. Path error:
   Error: cat: reports/tax summary.txt: No such file or directory

6. Correct path:
   cat "../../reports/$file1"

7. Path decision:
   Relative paths are useful when working within a known directory structure.
   Absolute paths identify the complete location and can be useful when accessing
   files from different working directories.
